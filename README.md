# Primera Marcha

Simulador para aprender a manejar un auto con caja manual, desde el asiento del conductor.

- Embrague, freno y acelerador con el teclado (A, S, D) y control fino del embrague con la rueda del mouse.
- Palanca de cambios con el mouse (o teclas 1–5, R, N).
- Volante con las flechas ← →, señalizadores con Z y X.
- Ciudad con semáforos, señales PARE, tránsito y zona para practicar estacionamiento.
- Misiones, puntaje y explicación de por qué se apagó el motor.

## Cómo usarlo

Abre `index.html` en un navegador de computadora (Chrome, Edge, Firefox o Safari) y haz clic en la calle para usar el teclado. Necesita internet para cargar la parte 3D.
